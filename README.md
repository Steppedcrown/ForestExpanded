# Forest Platformer

A platformer game built with [Phaser 3](https://phaser.io/) featuring dynamic physics-based gameplay with exploration and checkpoint mechanics.

Play on GitHub Pages: https://steppedcrown.github.io/ForestExpanded/

## Gameplay

Navigate through a forest platformer level filled with challenges and secrets. The game features:

- **Physics-based movement**: Jump, slide, and dash your way through the level
- **Checkpoints**: Collect checkpoints to save your progress and respawn points
- **Exploration**: Multiple paths and hidden areas to discover
- **Precision platforming**: Variable jump height and momentum-based movement mechanics
- **Fluid controls**: Acceleration and drag mechanics create responsive, satisfying movement

## Controls

| Action | Control |
|--------|---------|
| Move Left | `Left Arrow` or `A` |
| Move Right | `Right Arrow` or `D` |
| Jump | `Space Bar` |
| Pause Game | `ESC` |
| Respawn at Checkpoint | `R` |
